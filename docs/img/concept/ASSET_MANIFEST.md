# Concept Asset Manifest

이 폴더는 Phase 0 기초 자료용 이미지 애셋을 보관한다. 현재 파일들은 게임 런타임용 최종 스프라이트가 아니라, 캐릭터 실루엣, 세력 언어, UI 무드, 재화/소품 방향을 잡기 위한 콘셉트 레퍼런스다.

## Usage Notes

- 문서, 피치덱, 무드 보드에는 바로 사용할 수 있다.
- Godot 프로젝트에 넣기 전에는 투명 배경 정리, 해상도 축소, 가장자리 클린업, 저작/라이선스 메모 확인이 필요하다.
- 실제 게임 스프라이트로 사용할 때는 모바일 가독성을 위해 축소 테스트와 실루엣 대비 테스트를 먼저 진행한다.
- 세력 콘셉트는 개별 NPC 기억/승격 구조가 아니라 세력 단위 시각 언어를 설명하는 용도로만 사용한다.
