# Legal Risk Notes

이 문서는 법률 자문이 아닙니다. 상용 출시 전에는 변리사 또는 게임 IP 변호사의 검토가 필요합니다.

## Main Risk Area

Shadow of Mordor / Shadow of War로 유명한 Nemesis 계열 시스템은 공개 특허 문서가 존재합니다. 이 프로젝트는 다음 요소를 의도적으로 피하는 방향으로 설계되었습니다.

## Avoid These in Implementation

1. 플레이어를 죽인 특정 일반 적이 이름 있는 보스로 승격되는 구조.
2. 적 NPC들이 랭크/위계도에서 승진·강등되는 구조.
3. 특정 NPC가 플레이어와의 과거 전투를 직접 기억하고 대사·외형·능력치를 바꾸는 구조.
4. 특정 NPC의 변화가 다른 NPC의 권력 상태 또는 랭크를 바꾸는 구조.
5. 다른 플레이어의 적 데이터를 가져와 복수 미션처럼 사용하는 구조.
6. 특정 보스/캡틴의 속성이 요새/거점 방어 구조와 1:1로 묶이는 구조.

## Safer Direction Used Here

- 개별 NPC 중심이 아니라 세계/지역/세력 중심 기록.
- 위계도 대신 Region Ledger와 Faction Grievance 사용.
- 승격 복수 NPC 대신 Omen Card와 Ritual Queue 사용.
- 오프라인 개인 월드 중심.
- 보스는 고정 캐릭터이며, 플레이어 행동에 따라 의식 카드만 조합됨.

## Pre-launch Checklist

- 게임명 상표 검색.
- 앱스토어/스팀 동일·유사 이름 검색.
- 도메인/SNS 핸들 검색.
- Nemesis 관련 특허 청구항과 실제 구현 비교.
- 외주 애셋 라이선스 확인.
- 폰트 상업 이용 가능 여부 확인.
- 사운드 효과/음악 라이선스 확인.
- 개인정보 처리방침 준비.
- 국가별 연령등급 확인.
- 오픈소스 라이선스 고지 준비.
