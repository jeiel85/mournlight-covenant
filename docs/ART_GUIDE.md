# Art Guide

## Visual Identity

- Theme: 장송 판타지, 달빛, 저주받은 왕국, 기억의 장부.
- Mood: 신비롭고 비장하지만 순수 공포는 아님.
- Camera: 2D top-down gameplay, cinematic pixel-art marketing key visuals.
- Readability: 작은 모바일 화면에서도 실루엣과 공격 타입이 읽혀야 한다.

## Gameplay Readability Rules

1. 플레이어의 장송등은 항상 가장 따뜻하고 밝은 노란색 계열로 유지한다.
2. 적의 공격 예고는 배경보다 높은 명도 대비를 가진다.
3. 독/가시/화염/달빛/망령 이펙트는 서로 다른 색상 언어를 가진다.
4. UI 패널은 깊은 남색 바탕 + 달빛 테두리 + 장송 금색 강조를 기본으로 한다.

## Store Key Visual Requirements

- 16:9 wide banner.
- No text, no logo, no UI.
- 중앙에 작은 Mourning Warden.
- 주변에 5개 세력 실루엣.
- 하늘에 룬 장부 형태의 빛나는 기록.
- 바닥에 전투 흔적: 깨진 검, 독 꽃, 재, 동전, 검은 가시.
